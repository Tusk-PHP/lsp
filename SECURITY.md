# Security Policy

## Reporting a vulnerability

Please don't report security vulnerabilities in public issues, discussions or pull requests.

Report them privately through GitHub: open the repository's [Security tab](https://github.com/Tusk-PHP/lsp/security) and choose **Report a vulnerability**. Only the maintainers can see the report. We'll reply there, work on a fix with you, and publish an advisory once a fixed release is out.

Include what you can: the affected version, how to reproduce it, and what an attacker could do with it.

## Supported versions

Fixes go into the latest release. Tusk PHP is on `0.x`, so older versions don't receive backported fixes; update to the latest release.
